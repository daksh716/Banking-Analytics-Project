# Banking Analytics & Fraud Monitoring Using SQL Server

## Project Overview
This project analyzes banking customers, accounts, transactions, merchants, and fraud alerts using Microsoft SQL Server.

## Tools Used
- Microsoft SQL Server
- SQL Server Management Studio (SSMS)
- SQL

## Database Tables
- Customers
- Accounts
- Merchants
- Transactions
- FraudAlerts

## Key Analysis
- Overall transaction amount and average transaction value
- Successful, failed, and pending transaction analysis
- Payment channel analysis
- Customer transaction ranking using `RANK()`
- Fraud risk categorization using `CASE`
- Customer-wise account balance and transaction analysis
- Monthly transaction trends

## SQL Concepts Demonstrated
- Joins
- Aggregate functions
- GROUP BY and ORDER BY
- Common Table Expressions (CTEs)
- Window functions
- CASE expressions
- Views
- Data validation and duplicate handling

## Views
- `vw_CustomerBankingSummary`
- `vw_FraudMonitoring`
- `vw_TransactionAnalysis`

## Project Purpose
The goal is to demonstrate SQL-based data analysis, fraud monitoring, and reporting skills relevant to a Data Analyst role.
